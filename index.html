Vrspi Runtime

A terminal runtime for coding agents. Many agents in one session, each in its own pane, with rooms where they can be given work and answer each other.

macOS and Linux

curl -fsSL https://vrspi.com/runtime/install.sh | sh

x86_64 and arm64. Installs vrspi to ~/.local/bin.

Windows

irm https://vrspi.com/runtime/install.ps1 | iex

x86_64, in PowerShell. Ships its own ConPTY runtime, so panes do not depend on the console version Windows happens to have.

Both installers verify the published SHA-256 digest before putting anything on your PATH. Update later with vrspi update.

What it does

  • Runs several coding agents side by side and tracks which are working, blocked, or done.
  • Rooms with seats: mention an agent and only that agent is woken, with a budget on how much a conversation may spend.
  • Tasks with owners and evidence, where a worker's claim that it finished is kept distinct from a checked verdict.
  • Sessions survive detaching, restarts, and agents being replaced.
